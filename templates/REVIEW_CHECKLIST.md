# Review checklist

Purpose: what the independent reviewer checks. The reviewer only reads and writes the review file.

Classify each finding as must (wrong or missing), should (weak or unclear), or nit (polish).
1. Facts and numbers match the sources or the saved run records.
2. Code examples run as shown; outputs match.
3. Figures show what their captions say.
4. The exercise can be solved from the page alone and its answer is correct.
5. Nothing is claimed that was not verified; limits are stated.
6. Style guide checks pass on the current file hash.
